## 一 定位

一句话：**本地 PDF 工作台——阅读、注释、页面管理、表单、打印，五件事做到顺手，不装 Acrobat。**

家族分工：Voluma 管 PDF 的读与改；画 PDF（排版产出）是 Foliox 的事，动效导出是 Tempus 的事。不做的：不做 OCR、不做云端签名服务、不做文档转换工厂（批量转换是 FangBox 工具线的事）。

## 二 一期范围（八件事）

1. **阅读**：打开秒开；连续 / 单页 / 双页（书籍对开）三种模式；缩放 8%–6400% 以光标为锚点；适应宽度 / 适应页面；平移（空格 / 中键）
2. **导航**：目录侧栏（书签树）、缩略图侧栏、页码跳转、关闭后重开自动回到上次阅读位置
3. **搜索**：全文搜索、结果面板、当前结果与全部结果高亮区分、`Enter` 逐个跳转
4. **注释**：高亮 / 下划线 / 删除线、矩形 / 椭圆、画笔（压感不需要，平滑要）、文字便签、图钉；注释直接写成 PDF 标准注释对象，注释列表面板（按页 / 按时间排序、点击跳转、可删除改色）；停手 1.2 秒自动保存
5. **页面管理**：旋转单页 / 全部、删除页、缩略图拖拽重排、提取选中页为新 PDF、插入其他 PDF 或图片为页
6. **表单**：AcroForm 填写（文本框 / 勾选 / 单选 / 下拉）、填写内容保存、导出展平（表单变固定内容）
7. **打印**：系统打印对话框、页码范围（全部 / 当前 / 自定义区间）、缩放模式（实际大小 / 适应纸张 / 多页合一）、双面选项
8. **夜间阅读**：页面颜色反转（白底黑字 → 夜间暖灰底），只反转页面渲染不反转 UI 主题

配套：注释自动保存（停手 1.2 秒整份原子写回 PDF，首次保存留一份 `.bak` 原件）、最近文件列表、打开加密 PDF 输入密码（只解密阅读，改密码不做）。

## 四 技术路线

### 4.1 双引擎架构

| 层 | 选型 | 管什么 |
| --- | --- | --- |
| 渲染层（前端） | **PDF.js**（Apache-2.0） | 页面绘制、文本层（选中/搜索）、注释层与表单控件定位——WebView 内跑，交互零 IPC |
| 处理层（Rust） | **lopdf**（MIT） | 注释读写、表单字段读写与展平、页面旋转/删除/重排/提取/插入 |
| 字形层（Rust） | **ttf-parser**（MIT/Apache-2.0） | 展平中文表单时读取系统字体轮廓，直接写成 PDF 矢量路径，不嵌入字体文件 |
| 兜底层（Rust） | **qpdf**（Apache-2.0，后续） | 加密文档处理、线性化、结构修复 |

为什么双引擎：PDF.js 的文本层和注释交互是现成的，自研命中测试要几周；但写盘、页面手术、打印这些必须 Rust。M2/M3 的注释、页面和表单全部用纯 Rust 的 lopdf 直接改对象树，**不引入 pdfium.dll**，安装包保持 5MB 级。

### 4.2 Rust voluma-core

| 职责 | 用到的 crate / 库 |
| --- | --- |
| 读取 PDF 字节、探测文件 | `std::fs` |
| 注释读取（标准 `/Annots`） | `lopdf` |
| 注释写回 + `/AP` 外观流 | `lopdf` |
| 页面操作（转/删/排/提取/插入） | `lopdf` |
| 表单字段读写与展平 | `lopdf` + `ttf-parser`（中文矢量字形） |
| 打印（M4） | 系统打印 API（GDI） |
| 最近列表 / 阅读位置 | 前端 `localStorage`（`voluma.recents.v1`） |

**命令清单（当前已实现）**：

```
read_document / file_exists / file_size
read_annotations / save_annotations
document_page_count / apply_page_plan / extract_pages
save_form_values / flatten_form
```

后续再补 `print_run`。页面旋转/删除/重排/提取/插入由 `apply_page_plan` 与 `extract_pages` 两个命令覆盖，不拆成五个 IPC。

**红线**：翻页、缩放、注释绘制、文本选择全部前端 PDF.js；Rust 只做「一次调用、一次返回」的慢活，跨 IPC 的热路径一律禁止。

### 4.3 注释存储（M2 定稿：直接写 PDF）

- **不再产生 `.voluma.json` sidecar**。注释就是 PDF 标准注释对象，文件本身就是成品。
- 类型映射：Highlight / Underline / StrikeOut / Square / Circle / Ink / Text（便签 `/Name /Comment`，图钉 `/Name /PushPin`）。
- 身份：每条注释带 `/NM voluma-…` 与 `/T Voluma`，回读与去重靠 `/NM` 前缀，绝不碰其他软件写的注释。
- 坐标：全部存 PDF 用户坐标；选区经 `viewport.convertToPdfPoint` 换算，回显经 `convertToViewportPoint/Rectangle`。
- 外观：为每种注释生成 Form XObject `/AP /N`，高亮带 0.4 alpha 与 Multiply，保证 Acrobat / Chrome / 系统预览都能看到。
- 保存：前端的 1.2 秒防抖 → Rust 后台线程整份重写 → 同目录临时文件 → 原子替换；**仅首次保存**复制一份 `<文件名>.pdf.bak` 留原件。
- 代价：每次保存重写整份文件，大文件偏慢；已有数字签名会失效。M2 先保证正确性，M3 再做增量/分页优化。
- 阅读位置、缩放这类非文档内容仍放 `localStorage`，不塞进 PDF。

### 4.4 页面管理（M3）
- 前端 `PageManager` 用 PDF.js 生成缩略图（48 页一屏懒加载），支持点选多页、左右转 90°、删除、HTML5 拖拽重排、插入 PDF / 图片占位卡、提取选中页。
- Rust `pages.rs` 只收一份页面计划 `{ pages, order, inserts }`，一次调用完成重排 + 删除 + 插入；页号一律 1-based，插入位置为最终页序 0-based。
- 旋转写每页 `/Rotate`（叠加在原生旋转上）；删除页时同时删页面对象、直接注释、`/Annots` 引用；插入图片按 150 DPI 编成单页 PDF（A4 横向，等比居中）。
- 缩略图按「原生旋转 + 增量」渲染，重开文档后仍显示 `↻ 90°`；删除只在最终应用时确认一次；提取与插入都用原生文件对话框。

### 4.5 表单填写与展平（M3）
- 控件层：PDF.js `AnnotationLayer` + `renderForms` 在每页生成原生文本框 / 多行框 / 勾选 / 单选 / 下拉，值写入 `doc.annotationStorage`；`scanForms` 按字段名聚合，`collectFormValues` 负责回读。
- 保存：停手 1.2 秒或点「立即保存」，Rust 读取 `/AcroForm` 字段树，按全名匹配，写 `/V`、按钮写 `/AS`；ASCII 文本重新生成 `/AP /N` 外观流，非 ASCII 文本置 `/NeedAppearances true` 交给阅读器再生成。
- 展平：同一次命令里应用当前值，把每个 Widget 的 `/AP` 作为 Form XObject 压进页面内容流，删除 Widget 与 `/AcroForm`，另存目标文件；原文件不动。
- 中文展平：Rust 用 `ttf-parser` 读取系统中文黑体（微软雅黑 / 思源黑体 / 苹方），把每个字转成 PDF 路径填充，**不嵌入字体、不依赖阅读器中文字体**；找不到字体时明确报错而不是输出乱码。
- 限制：表单保存与注释保存是两次串行写盘；中文展平只输出矢量字形，文本不可再搜索/复制；数字签名会在任何写回后失效。

## 五 文件格式

PDF 是外部标准，也是 Voluma 唯一的工作文件；不发明格式、不生成旁挂数据。一次保存后磁盘上只会多一个首次留底的 `.bak`：

- `书.pdf`：原文件 + 标准 `/Annots`，Acrobat、Chrome、macOS 预览、WPS 都能看到
- `书.pdf.bak`：第一次保存前的原件，之后连续自动保存不再覆盖
- 阅读位置 / 缩放 / 最近文件：WebView `localStorage`（`voluma.recents.v1`），不写进 PDF

## 六 设计规范

### 6.1 家族统一（与 Chapter / Groma 同口径，写死）

- 圆角令牌 6 / 8 / 12 / 16 / 999；间距 4 的倍数；字号 12 / 13 / 14 / 16 / 20 / 26 / 34
- 真磨砂玻璃：三层带 alpha 底色 + `blur(22px) saturate(1.5)` + 1px 半透明亮边 + 顶部内高光 + `feTurbulence` 噪点（opacity .035）；只用于顶栏、侧栏、弹窗、工具条浮层；**阅读区永远实底**
- 动效三档（完整 / 精简 / 关），120 / 180 / 280 ms，`--ease-out`；必做：启动页淡出、欢迎页卡片浮入、侧栏滑入、缩略图切换、翻页过渡（120ms，可关）
- 启动页 400–800ms 淡出，与欢迎页同底色不闪白；欢迎页左栏入口 + 最近 PDF 卡片墙（封面取首页缩略图，240×180，显示进度「读到 42/312 页」）
- 深色模式一期不做（二期 UI 层），令牌成对预留

## 八 性能与验收

**性能红线**：100MB / 500 页 PDF 打开 ≤ 2s；翻页 ≤ 100ms（预渲染当前 ±2 页）；连续滚动内存 ≤ 400MB；缩略图批量 500 页 ≤ 10s（后台跑不卡 UI）；安装包 ≤ 60MB（M3 Release 单 exe 4.76MB，不含 pdfium）。

**界面验收清单（节选）**：

- [ ] 启动页与欢迎页同底色，切换不闪白
- [ ] 双页模式中缝有书脊阴影
- [ ] 注释工具条玻璃层能透出底下页面
- [ ] 注释列表点击跳转、删除改色即时生效
- [ ] 注释写回后，Acrobat / Chrome / 系统预览都能看到
- [ ] 首次保存留下 `.bak`，连续保存不覆盖原件
- [ ] 提取页生成的新 PDF 在别的阅读器可开
- [ ] 展平后的表单不可再编辑
- [ ] 缩放始终以光标为锚点，`Ctrl+0` 回 100%、`Ctrl+1` 适应宽度

## 附录 B Voluma 应用图标

**符号构图**：两张 A4 比例纸页错位叠放——后页向右下偏移 32px，前页右上角折角（折角边长 180px，内侧露 8% 暗部）；前页顶部垂下一条宽 72px 的书签缎带，末端燕尾切口；前页表面两条短横线示意文字。全部白色线稿，线宽 64px。

```
two offset portrait pages (A4 ratio), back page offset 32px to bottom-right,
front page with a folded top-right corner (180px fold) showing an 8% darker
```
